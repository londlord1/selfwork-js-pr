# Самостоятельные работы по JavaScript — одна страница на ПР

Второй вариант сайта: **одна HTML-страница на одну практическую работу** (ПР03–ПР32).
Внутри страницы — кнопки заданий, выбранное задание открывается в iframe.

- `index.html` — список всех практических.
- `pr03.html` … `pr32.html` — по одной странице на ПР, внутри все её задания.
- `build_pr_pages.py` — сборка страниц из репозитория с отдельными задачами.

## Как устроено

Каждая страница ПР самодостаточна: HTML всех её заданий встроен в `srcdoc` iframe,
внешние файлы задач не нужны. Стили и скрипты заданий изолированы iframe'ом, поэтому
одинаковые `id` и глобальные переменные не конфликтуют.

Высота iframe подстраивается под содержимое через `postMessage`.

## Пересборка

```bash
python3 build_pr_pages.py --src ../selfwork-js
```

Скрипт читает страницы `прXX_задN_*.html` из соседнего репозитория
[`selfwork-js`](https://github.com/londlord1/selfwork-js) и пересобирает `prXX.html`
и `index.html`.

## Примечания

- ПР26–ПР32 используют React 18 и Babel с CDN — для них нужен интернет.
- Остальные страницы работают офлайн.
- Отдельные страницы по задачам остаются в репозитории
  [`selfwork-js`](https://github.com/londlord1/selfwork-js).
