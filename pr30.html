ПР30 — React: обмен данными через API (все задания)

Одно React-приложение цитат с локальной имитацией API (async/await + задержка). Здесь реализованы все 7 заданий: копирование цитаты, выбор количества, автодополнение авторов, избранное в localStorage, пагинация, кэширование запросов и «Цитата дня» с эффектом печатной машинки.
